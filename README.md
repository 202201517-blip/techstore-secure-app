# TechStore Secure App

Proyecto grupal de la materia Seguridad Aplicada en Apps Móviles.

## Descripción

TechStore Secure App es una aplicación móvil de tienda en línea segura enfocada en la venta de productos tecnológicos.

El sistema permitirá que los usuarios puedan registrarse, iniciar sesión, visualizar productos, agregarlos al carrito y realizar pedidos.

## Tecnologías

- Android Studio
- Kotlin
- Spring Boot
- PostgreSQL
- JWT
- BCrypt
- Postman
- GitHub

## Estructura del proyecto

- backend/: API desarrollada en Spring Boot.
- mobile/: Aplicación móvil desarrollada en Android Studio.
- database/: Scripts SQL de la base de datos PostgreSQL.
- evidencias/: Capturas y evidencias del avance semanal.

## Estado del proyecto

Base de datos PostgreSQL creada y repositorio GitHub preparado desde develop.
